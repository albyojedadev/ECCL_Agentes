# Procedencia y uso de las fuentes

knowledge/sources/GPTs conserva el material original disponible, con huellas SHA-256 en source_manifest.json. No es un conjunto de instrucciones para ejecutar de forma indiscriminada: las skills indican qué manual o ejemplo cargar para cada tarea.

Clasificación: instrucciones originales, conocimiento histórico, ejemplos sintéticos, especificaciones de integración no conectadas y documentación auxiliar. Los binarios se preservan como archivo, sin presumir equivalencia con versiones textuales. Se excluyen únicamente bloqueos temporales de ofimática.

Los nueve JSON de origen mal formados se conservan sin alteración. La normalización de seis avatares repara solo delimitadores, deja recibo de cambios y conserva identidades/contenido. Los bancos literarios truncados no se completan fingiendo originales; las partes completas pueden leerse como texto, con sus límites.

La normalización de siete cursos conserva cada fila íntegra y separa su periodo textual no cabecera. No inventa fechas ISO ni disponibilidad. Todos los datos académicos quedan como snapshot no verificado en la web en esta corrección.

Marca, contratos y políticas propuestas tienen estado pendiente de validación, fuente de elaboración y límites. Que una propuesta resulte coherente internamente no la convierte en política aprobada.

Este corpus fue comprado/preparado para el cliente; comprueba el destino y las condiciones de difusión antes de publicarlo. La licencia del paquete es propietaria. Una URL pública del código no equivale por sí sola a permiso para publicar manuscritos o datos futuros de alumnos.
