## Decisiones de calibración
1. Identifica un problema comprobado en el texto nuevo; busca ID compatible, no una identidad similar.
2. Lee informe y comentario completos del caso. Observa qué evidencia sostiene la recomendación y qué tono la hace útil.
3. Contrasta con la consigna nueva y las partes disponibles. Un objeto visible no demuestra conflicto: busca consecuencia; si no existe, explica esa diferencia.
4. Rechaza inferencias personales heredadas. Sustituye «eres tímido» por descripción verificable de focalización/distancia solo cuando el texto la sostenga. No alteres el original archivado; aplica esta interpretación en la nueva salida.
5. Elige una prioridad y una acción que el alumno realice. No entregue una paráfrasis del comentario histórico con el nombre cambiado.

## Forma deliberada frente a defecto
Ante fragmentación, repetición o ruptura de linealidad, pregunta intención/consigna y examina efecto: ¿hay patrón, orientación temporal o contraste reconocible? Una fragmentación coherente puede sostener el efecto aunque no use puentes convencionales. Si falta continuidad por fragmento incompleto, marca no evaluable en vez de imponer estructura lineal.

## Protocolo de revisión humana
Comprueba cita real → efecto razonado → recomendación propia; narrador distinto de autor; género/consigna; informe técnico sin metáforas; comentario con una prioridad; canal/destinatario autorizado. Registra decisiones inciertas para docente. Este índice orienta lectura; no certifica conducta del modelo ni sustituye evaluación docente del comentario concreto.
