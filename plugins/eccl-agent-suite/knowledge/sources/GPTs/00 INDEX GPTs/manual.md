# 1. GUÍA RÁPIDA · QUÉ ASISTENTE USAR SEGÚN LA NECESIDAD
--------------------------------------------------------------------

Esta sección sirve como punto de entrada para cualquier miembro del
equipo. Aporta un mapa rápido de navegación por los asistentes.

Contenido detallado: ver Manual Word · Sección "Página inicial".

Ítems principales:
- Validar ideas, cursos o campañas → Consejo de Alumnos Sintéticos  
- Diseñar programas → Generador / Propuestas Formativas  
- Buscar subvenciones → Analista de Subvenciones  
- Redactar textos institucionales o literarios → Ghostwriter  
- Corregir ejercicios de alumnos → Crítico Literario  
- Si no sabes qué usar → Consulta guiada por necesidades
