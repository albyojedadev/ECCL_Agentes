# Suite de Agentes ECCL

Plugin declarativo para ChatGPT y clientes compatibles con Agent Plugins 1.0.

Incluye:

- 17 skills de rol, una por agente ECCL.
- 24 skills procedimentales.
- Una skill de puesta en marcha y coordinación.
- Seis protocolos y las referencias documentales necesarias.

No necesita Python, Node.js, servicios locales ni credenciales empaquetadas. Las especificaciones históricas de APIs se conservan como documentación y no representan conexiones activas.
