# Instalación y carga

## ChatGPT · plugin ya instalado

Este directorio forma parte del plugin `Suite de Agentes ECCL`. El cliente no necesita instalar Python, Node.js, una terminal ni ningún programa auxiliar. Tras la instalación, puede invocar el plugin o describir la tarea para que sus skills se activen.

La autorización e importación desde GitHub se explica en el `docs/INSTALACION.md` de la raíz del repositorio. Este paquete contiene exclusivamente componentes declarativos y conocimiento.

Después de instalarlo, el usuario puede invocar `Suite de Agentes ECCL`, describir directamente su necesidad o pedir al coordinador que muestre los 17 roles y recomiende un recorrido.

El plugin no contiene scripts, ejecutables, credenciales ni conectores activos.
