# Manual de uso ECCL

## Elegir el asistente

Explique el objetivo, destinatario, datos disponibles y restricciones. El coordinador propone una ruta mínima y otra completa, con entradas y entregables; no debe decir que ha consultado a colegas cuando solo recomienda un flujo.

| Necesidad | Responsable | Preparar |
|---|---|---|
| Elegir curso o revisar información académica | Experto/orientador | Perfil, restricciones, edición y fuente actual |
| Decisión empresarial | Experto + analista de datos | Matrículas, costes, cobros/pagos, capacidad, fecha y alternativas |
| Ayuda pública | Analista de subvenciones | Bases, proyecto, antecedentes y documentos de soporte |
| Contrastar oferta o mensaje | Consejo de alumnos | Ficha/variantes, perfiles pertinentes y pregunta cualitativa |
| Redactar con voz de Antonia | Ghostwriter | Género, tono, propósito, datos y ejemplo de calibración |
| Corregir un ejercicio | Crítico | Texto, consigna, contexto y destinatario docente/alumno |
| Sostener la escritura | Compañero | Atasco, tiempo disponible, meta y límites personales |
| Preparar una antología | Editor | Corpus versionado, criterios, derechos y decisiones pendientes |
| Club o comunidad | Dinamizador | Lectura, participantes, modalidad, tiempos y moderación |
| Contratos/derechos | Asesor | Documento concreto, partes, uso, territorio/plazo y dudas |
| Incidencia técnica | Soporte | Plataforma, paso fallido, error y pruebas sin credenciales |
| Nota/dossier/propuesta | Prensa/B2B | Hechos verificables, destinatario, alcance, presupuesto y citas autorizadas |
| Pieza gráfica | Diseñador/guardián | Texto final, activos, formato y reglas de marca aprobadas |

## Flujos completos

**Oferta:** experto estructura hipótesis y alternativas → analista comprueba costes/capacidad con supuestos → panel contrasta objeciones simuladas → equipo decide qué validar con público real → comunicación prepara borrador con datos confirmados.

**Financiación:** analista extrae requisitos/baremo y entrevista lagunas → redacta bloques Copycat ECCL con evidencia → revisa presupuesto/plazos/adjuntos → persona responsable aprueba registro. Preparación no equivale a presentación.

**Crítica:** docente aporta consigna y texto → crítico elabora informe privado → produce comentario externo separado y revisable → docente decide devolución. Ante interlocutor alumno o rol desconocido, el agente protege el informe interno.

**Autoría:** acordar género/tono → cargar manual y ejemplos pertinentes → proponer estructura → redactar tramo → revisar exactitud/voz/copia → iterar según feedback. Un rango de longitud de frase no certifica fidelidad.

## Comandos históricos y navegación

El experto recupera /diagnóstico, /decidir, /oferta, /operaciones, /comercial, /proyectos, /finanzas y /plantillas. Los comandos son formas de solicitar procesos; no invocan una API ni cambian estado por sí mismos. Consulte su agente y la skill de catálogo/decisión para los entregables por modo.

Para encontrar material, consulta las referencias enlazadas por la skill activa y busca los términos pertinentes en `knowledge/sources/GPTs`. Los archivos conservan contenido histórico y referencias antiguas; contrasta datos y resuelve conflictos antes de aplicarlos.

## Corregir un resultado insuficiente

Pida al agente que identifique qué fuente cargó, qué requisito no cubrió y qué información falta. Solicite una revisión contra una rúbrica concreta, no «hazlo más profesional». Un buen resultado debe permitir verificar sus datos, decisiones y pendientes.

Ejemplo: «Distingue ingreso y cobro, muestra el cálculo con unidades y explica qué pasa si el umbral supera el aforo». Ejemplo literario: «Conserva la voz del alumno, cita el gesto que funciona y separa informe técnico de comentario externo».

## Límites y autorización

No suba tarjetas, contraseñas ni datos innecesarios de alumnos. Las muestras didácticas del paquete no acreditan publicaciones reales. Los agentes no pueden asegurar plaza, publicación, premio, aprobación de ayuda ni acceso a sistemas sin comprobación.

Los porcentajes de un panel sintético no son demanda observada. Las propuestas legales/gráficas pendientes deben cotejarse con documentos aprobados. Verificación estructural, evaluación de respuestas y validación humana son pasos distintos.
